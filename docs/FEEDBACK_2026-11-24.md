## Login as

- `POST /auth/login-as/:userId` (admin) returns a one-time ticket, valid 2 minutes. The new tab opens `/login-as#<ticket>`; the ticket is after `#`, so it never reaches a server log, and is removed from the address bar at once.
- `POST /auth/login-as/redeem` gives a session token for that tab only (sessionStorage, sent as a Bearer header). No cookie is set, so the admin stays signed in as themselves in every other tab.
- Same organisation, active accounts only, never yourself or the Super Admin; only the Super Admin may open another admin. The session lasts 2 hours, cannot change that person's password or two-step sign-in (`LOGIN_AS_LIMIT`), and cannot start another login as. Every start is in the audit log (`auth.login_as`) with the admin's name. A banner in the tab says whose account it is, with **Close this login**.
- Team chat in such a tab refreshes every 15 seconds instead of using the live connection, which would use the admin's cookie.

## Gate survey languages

- `Question.translations`: `{ "<lang>": { text, help, options: { <optionId>: label }, rows: { <rowId>: label } } }`. Language codes as on the market (`es`, `pt-BR`); `pt-BR` also matches `pt`, and the reverse.
- `POST /ai/translate-questions { language, questions }` (editors) uses the AI providers from Settings → Integrations and counts toward the AI allowance (kind `translate`). Nothing is saved until the person saves the project.
- Page texts (buttons, step titles, validation messages): English plus es, fr, de, it, pt, nl, ja, zh, ko, ru, ar (right to left), hi, tr, pl.
