## Recycle bin

- `DELETE /projects/:id` moves a project to the bin (`deletedAt`). Live projects are refused (`PROJECT_LIVE`): close them or put them on hold first.
- Binned projects are left out of every project read (`src/prisma/compat.ts`), so lists, reports, dashboards and the vendor portal no longer show them, and their links refuse respondents.
- Admins and the Super Admin may always delete. Others need **May delete projects** (Settings → Team, `User.canDeleteProjects`). Without it the API answers `DELETE_NEEDS_ADMIN` and the web offers **Ask to delete** (`POST /projects/:id/delete-request`), which shows on the bell and in the bin; admins approve (delete) or decline.
- `POST /recycle-bin/:id/restore` brings it back as it was. After 30 days an hourly job removes the project for good with respondents, links and invoices; admins can do this at once (`DELETE /recycle-bin/:id`).

## One entry per browser and device

The entry links set a first-party cookie (`pxb`, one year). With the switch on, a second entry carrying a cookie that already entered the project ends as Duplicate (`SAME_BROWSER_ENTRY`). Without the cookie (another browser, or the cookie cleared), an earlier entry from the same IP, device type and operating system also counts (`SAME_DEVICE_OTHER_BROWSER`). Test links are not checked. Per-vendor overrides work as for the other switches.

## Reports

`POST /reports/builder/{overall|client|vendor|conversion}` with `from`, `to`, `clientIds`, `contactIds`, `vendorIds`, `projectIds`, `projectManagerIds`, `salesPersonIds`, `projectTypes`, `countryCodes`, `statuses`, `approvals`, `groupBy`, `page`, `pageSize`, `export`.

- Aggregated reports split rows by the `groupBy` dimensions; the web picks them from the Data columns. Money is in the reporting currency (Vendor payables → Finance settings rates).
- The client report refuses vendor filters and dimensions; the vendor report refuses client filters.
- The conversion report defaults to completes; `SPEEDER` is a pseudo status. `POST /reports/builder/conversion/approval {sessionIds, approval}` skips completes on a client invoice or vendor bill (`locked`).
- Date presets: today, yesterday, this week (from Monday), this month, past month, this year, past year, all time, custom. Downloads: Excel and CSV, up to 50,000 rows.
